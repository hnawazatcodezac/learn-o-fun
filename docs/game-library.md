# Game library

The public launch ships 11 games across maths and early English, and the library grows to 47 games across six subjects. Each game is a reusable mechanic that serves several age bands and many skills through different activities, so the list of games stays far shorter than the list of things children learn.

**How to read the tables.** *Ages* is the full range a game can serve; each age band gets its own activities. *Item type* refers to the shared item types in section 6.4 of the plan; *self-driven* games own their flow (section 6.3). *Phase*: Slice is built in the vertical slice, Launch is in the first public release, Grow is Phase 3, Later is Phase 4 onward or on demand.

## Game brief template

Every new game starts as a one-page brief, reviewed by the learning designer before any code is written. It doubles as the prompt context when building the game with Claude Code.

- **Name and ages:** working title and the age bands it serves.
- **Target skills:** skill IDs from the skill graph, primary and secondary.
- **Core mechanic:** what the child physically does, and why that action embodies the concept rather than wrapping a quiz.
- **Item types and sources:** which shared item types it renders; template generator or authored bank.
- **Support ladder:** the game-specific hint and the worked "show me" for this mechanic.
- **Misconceptions:** the common wrong answers it can detect, and the explanation each one triggers.
- **Practice and Challenge:** what changes between the two modes.
- **Accessibility:** keyboard and switch path, non-colour cues, audio for every instruction.
- **Localization:** text, audio, cultural variants, and whether the scene mirrors right to left.
- **Playtest success:** what children should say or do in playtests for the game to ship.
